小番茄图片混淆

基于希尔伯特（Hilbert）空间填充曲线重排全部像素，并沿曲线做一次 黄金分割循环位移。整图被彻底打散，肉眼无法辨认；用相同密钥反向操作即可无损还原。

点击选择 或把图片拖到这里
支持多张 · PNG / JPG / WEBP / GIF / BMP

使用说明

密钥必须一致才能还原。密钥 1.000 等价于原始小番茄工具的默认偏移 round(0.618 × W × H)；输入 0.618 可得 round(0.618² × W × H)。
建议保持 PNG 输出。PNG 逐像素无损（实测往返误差 0）；JPEG 质量 0.95 对照片类图 平均误差约 1.2/255（肉眼几乎无感），但对细节极密的图可能到 32/255，且每次保存都会累积。 只有在必须与旧工具产物互通时才改用 JPEG。
关于透明图：浏览器 canvas 对半透明像素会做 alpha 预乘，含半透明区域的图片往返会有 ±2 左右的精度损失；不透明图片（绝大多数照片、截图）不受影响，完全无损。
把「里图」压进暗部、把「表图」放进亮部，按棋盘格交错 —— 正常看是表图，调阈值后显出里图。

交错方式与限制

两图阈值不能过近（里图阈值 必须小于 表图阈值），否则显形时会互相串色。

滑杆误触后可一键还原为：里图 24 / 表图 42 / 对比度 0 / slope 1 / gap 1 / max 1200
gap / slope 决定图案密度。gap=1、slope=1 时是 (x+y) mod 2 == 0 的对角棋盘； 调大 gap 或 slope 会让交错纹路变粗、抗压能力更强、但两图互相干扰也更明显。
