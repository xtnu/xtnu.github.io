字符画工坊 ASCII / 灰度映射生成器 · v2.1

把 图片 · 视频 MP4 · 摄像头 实时转成字符画：灰度采样 → 明暗映射 → 抖动量化，暗处用密字符、亮处留白。可导出 TXT / PNG / SVG / GIF / MP4，参数改动即时预览。全程本地运算，单文件、零依赖、不联网。参数会自动记忆，下次打开沿用；点右上「重置参数」恢复默认（保留当前已选文件）。
